# agent-purge v0.2.29

### ✨ 改进 (Improvements)

#### 1. 🐧 Linux 也有正式产物了：单文件二进制、`.tar.gz`、`.deb`

以前 Linux 用户只有 `npm install -g` 或源码两条路。现在 `release.yml` 多了一个 `build_linux` job，用 Bun 交叉编译 `linux-x64` / `linux-arm64`，每个架构产出：

| 产物 | 说明 |
|---|---|
| `agent-purge-<版本>-linux-<架构>` | 自带运行时单文件二进制，`chmod +x` 即用 |
| `...-linux-<架构>.tar.gz` | 便携包：`.desktop`、512px 图标、`LICENSE`、`README`、免 root 的 `install.sh` |
| `...-linux-<架构>.deb` | 装到 `/opt/agent-purge`，注册 `/usr/bin/agent-purge`、桌面入口与 hicolor 图标 |
| `...-linux-<架构>.AppImage` | 仅在 runner 能取到 `appimagetool` 时生成，不硬依赖 |
| `linux-manifest.json` | 上述产物的 SHA-256 汇总 |

构建脚本 `scripts/build-linux.mjs` 会**在本机架构上真实跑一遍 smoke**（`--help`、`status`、`--serve` 静态资源与版本号），并对 `.deb` 回读元数据与文件清单后才算通过；包内文件权限显式归一化，不继承宿主。

`test.yml` 新增 `linux-package` job，每次 push 都构建一次，防止这条通道悄悄坏掉。

#### 2. 📋 三语 README 支持表重修

原来的「支持情况」表有三处硬伤：中文表被空行截断成两张表；列头只有 3 列，却把抓包/BYOK/规则通道混塞进「同会话热切」；Qwen、Gemini、Crush、Kiro、Kilo、Antigravity、PI-Desktop 等 7 家根本没列。

现在统一成 5 列（执行器 / 已验证版本 / 主要接管通道 / 同会话热切 / 验证状态与实测说明），补齐 19 家，中英日三份同步。

#### 3. 🗂 规则文件页改名并覆盖全局

「项目规则」页更名为「规则文件」，顶部新增 **作用范围**（当前项目 / 全局目录）与 **写入人设** 选择；写入后状态显示 `已写入 · <人设名称>`，并可一键 `更新为「…」`原地替换托管块。全局侧覆盖 8 处已实测落点（Pi、Claude Code、omp、Grok、ZCode、Antigravity、Kilo、Crush），同样走 stash 原字节快照与「随时移除」。

### 📦 安装与升级 (Installation & Upgrade)

```bash
npm install -g agent-purge@latest                       # npm
sudo apt install ./agent-purge-0.2.29-linux-x64.deb      # Debian / Ubuntu
tar -xzf agent-purge-0.2.29-linux-x64.tar.gz && sh agent-purge-0.2.29-linux-x64/install.sh   # 免 root
```

Windows 便携包、安装器与 macOS `.dmg` 见本 Release 附件。AppImage 是否出现取决于构建机能否取到 `appimagetool`。
