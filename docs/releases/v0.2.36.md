# agent-purge v0.2.36

v0.2.35 的发布验收未通过，没有发布 npm 或 GitHub Release。
保留原 tag，不覆盖历史；本版本包含其全部修复与更稳健的 Windows 验收。

## Windows 桌面（#20）

- 静态链接 MinGW 运行库，消除窗口启动即 `0xC0000135` 的缺 DLL 问题；
  构建校验导入表，异常时拒绝发布。
- 原生宿主启动失败时记录日志并回退浏览器，修复重复开窗。
- 正在运行的窗口/启动器会阻止覆盖安装或卸载，避免被占用的 EXE/DLL 残留。
- 卸载确认之后才撤销配置；严重还原失败仍阻止卸载，旧记录可跳过并保留凭据。
- 清理预览不写用户数据、迁移配置或回滚 journal。
- 所有工具的展示统一，不再显示“专属”徽标；独立人设设置保留。

## 验收与产物

- Windows 实际安装、重装、原生窗口、单例、关窗、冲突处理和卸载。
- Windows/Linux/macOS × Node 20/22/24 测试与 npm tarball 验收。
- Linux x64、ARM64 原生 runner 分别验证单文件、便携安装、Debian
  安装/运行/卸载，以及可选 AppImage。
- 修复 Windows 验收对继承 PowerShell 环境和短查询超时的依赖，
  保留原始失败原因，上传安装日志，不降低发布检查要求。
- Windows ZIP/setup/独立 EXE，Linux x64/ARM64 单文件/tar.gz/deb/AppImage，
  macOS arm64/x64 DMG；校验值见 `SHA256SUMS.txt`。
- macOS DMG 仍未签名/公证，首次运行需按系统安全提示手动允许。
