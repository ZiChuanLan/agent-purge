# agent-purge v0.2.37

### 🐌 Windows 首屏不再等不可达的网络映射盘（#22）

- 启动探测要遍历 `C:` 到 `Z:` 找桌面端。断线的网络映射盘上 `existsSync` 要等 SMB 超时，
  实测每个约 21 秒，期间 Node 的事件循环整个堵死：`GET /api/state` 40 秒以上才返回，
  控制台停在「正在读取人设说明…」，连心跳都跟着排队。
- 现在先读 `HKCU\Network` 拿映射盘符（语言无关、约 12 毫秒、缓存 5 分钟），把网络盘从探测
  名单里剔掉，只探本地盘（0–1 毫秒一个）。报告者机器上 `detect()` 49.4 秒 → 本机实测
  `fixedDrives()` 首次 23 毫秒、`detect()` 0.4 秒以内。
- 注册表里查不到的会话内映射（`net use /persistent:no`）第一次仍会等超时，但量到一次慢盘之后
  本轮进程不再问第二次，盘符缓存过期刷新也不会再卡一遍。
- 装在网络盘上的桌面端仍由开始菜单快捷方式与注册表卸载项定位，不受这个过滤影响；
  `AGENT_PURGE_DRIVES` 手工指定扫描根的老办法照旧。
