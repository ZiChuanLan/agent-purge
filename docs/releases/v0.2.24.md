# agent-purge v0.2.24

### 🔧 修复与优化 (Fixes & Improvements)

#### 1. 🛡️ 增加 DSH 存量旧版配置静默就地自愈机制（消除 pnpm v11 prune 导致的启动崩溃）
- **背景**：v0.2.19 及更早版本将插件写入 profile 的 `node_modules`，并在 `cordis.patch.yml` 中使用裸包名。宿主自带的 pnpm v11 在执行插件安装或依赖重整时，会将未在 `package.json` 声明的目录当成孤立依赖清理掉，导致 DSH 启动报错 `Cannot find package 'agent-purge'`；若未重装，用户安装其他插件也会报错。
- **改动**：
  - **就地自愈 (Self-Healing)**：在只读查询与探针链路（`status` / `probe`）中增加 `healStaleProfiles()`，只要数据目录中存在新版插件包，自动将旧版裸包名重写为绝对规范的 `file:` URL，消除 YAML 根部残留的空数组 `[]`，并安全收回 `node_modules` 下的旧版副本。
  - **状态判定收紧**：`blockAlive` 严格核验 patch 块内是否为规范的 `file:` URL 且数据目录真实存在文件，杜绝旧副本被清理后的假阳性报告。
  - **运行留痕**：自愈操作自动在 `<数据目录>/dsh.log` 记录留痕日志，保障完全可追溯。

#### 2. 🧪 补齐 DSH 跨版本真机测试矩阵与请求体抓包验证
- 实测验证 DSH 0.2.1-rc.2（loader 1.0.6）、0.2.1-rc.5（桌面版 Electron）与 0.2.2-rc.1（loader 1.1.0）全版本兼容性。
- 通过本地 loopback 抓包验证四种模式发往大模型的实际提示词请求：`strict` 模式从宿主默认 2729 字符彻底纯化为 112 字符纯净人设，宿主身份声明完全剥离。

### 📦 安装与升级 (Installation & Upgrade)

```bash
npm install -g agent-purge@latest
agent-purge status
```
> 存量 DSH 用户无需手动重新安装，升级后执行一次 `agent-purge status` 或打开 Web 界面即可自动完成就地自愈。

便携版与安装器见本 Release 附件（`agent-purge.exe` / `agent-purge-0.2.24-setup.exe`）。
