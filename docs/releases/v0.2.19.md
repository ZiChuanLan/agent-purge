# agent-purge v0.2.19

### 🌟 核心更新亮点 (Highlights)

#### 1. 🪟 修复 Windows `--app` 窗口隐藏与白块残留（issue #9）
- **根因**：`lib/window.mjs` 使用 `windowsHide: true` 启动浏览器。Windows libuv 将其转换为 `SW_HIDE`；当 Edge 未在后台运行时，Chromium 主窗口以 `WS_VISIBLE = 0` 创建，出现无标题栏、点击穿透、任务栏无图标但桌面残留 DirectComposition 纯白合成矩形的现象。
- **修复**：浏览器为 GUI 应用程序，启动时指定 `windowsHide: false`，确保窗口正常可见可交互。

#### 2. 🔌 端口占用时二次启动自动依附并开窗
- **现象**：老实例正在运行（如双击第二次 `agent-purge.exe` 或老会话未完全退出），端口 7788 报 `EADDRINUSE`，静默退出无任何提示或窗口。
- **修复**：遇 `EADDRINUSE` 时主动探测 `http://127.0.0.1:7788/api/state`；确认已有 agent-purge 服务正常存活后，直接调用 `openAppWindow()` 把窗口开到已有服务上并正常退出，避免静默黑洞。

#### 3. 🛡️ 完善合规守则与免责声明
- 在 README 与 `docs/LEGAL.md` 明确强调：本项目仅为本地多宿主配置管理工具，严禁用于对抗或未授权访问，不分发违规/越狱载荷。

#### 4. 🔄 修复 Web 控制台页面刷新导致本地服务误退出（PR #10）
- **根因**：页面卸载（F5/Ctrl+R 刷新）触发 `pagehide` 事件并直发 `/api/exit`，服务端误当作关机而立即退出进程。
- **修复**：将页面卸载与服务关停解耦，改为上报世代代号 `/api/leave?gen=N`。服务端引入 1500ms 退出宽限期，页面刷新时由新请求立即撤销倒计时，同时忽略旧页面迟到的 beacon。源码态永不因页面离开退出。
