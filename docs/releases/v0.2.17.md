# agent-purge v0.2.17

### 🌟 核心更新亮点 (Highlights)

#### 1. 🖥️ 新增 PI-Desktop 通道（含真机实测热切换）
- **识别**：`~/.pi-desktop` 数据根 + 安装目录（含 `PI-Desktop-Portable-*.exe` 便携版），不会再把 pi CLI 误认成 PI-Desktop。
- **常驻**：写 `~/.pi/agent/SYSTEM.md` 托管块，替换产品 persona 块（64 KiB 上限），新建会话生效。
- **热切**：PI-Desktop 0.21 起扩展只能由插件贡献（ADR 0215），agent-purge 以 imported 插件方式装入 `plugins/imported/agent-purge` 并登记 registry，`before_agent_start` 每轮读 `state.json`。
- **实测**：同一会话里把 state 人设从小码酱改成大肥鱼，下一轮回答即切换；`/purge off` 后恢复默认。首次安装插件需重启一次 PI-Desktop。

#### 2. 🧭 可执行文件通配匹配
- `locate()` 支持 `PI-Desktop-Portable*.exe` 这类带版本号的便携版命名；通配只在显式写 `*` 时生效，`Antigravity.exe` 不会误吃 `antigravity-tools.exe`。

#### 3. 🧹 移除未成立的通道
- 删掉 TRAE CN / Qoder CN 两条 harness：它们只有规则/记忆层，无法替换系统提示词，避免给出“能改身份”的错误暗示。

### 📦 安装与升级 (Installation & Upgrade)

```bash
npm install -g agent-purge@latest
agent-purge web
```

便携版与安装器见本 Release 附件（`agent-purge.exe` / `agent-purge-0.2.17-setup.exe`）。
