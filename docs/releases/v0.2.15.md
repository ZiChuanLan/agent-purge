# agent-purge v0.2.15

### 🌟 核心更新亮点 (Highlights)

#### 1. 🚪 便携版与安装版窗口关闭即退出后台（彻底解决 Issue #7）
- **心跳保活与超时自毁**：服务端实现 `autoExit` 机制。当 Web 窗口关闭且心跳中断超过 8 秒（预留 F5 刷新缓冲），或启动后 30 秒无连接，后台服务自动释放 HTTP 端口并安全退出。
- **页面卸载通知**：Web 前端在 `pagehide` 事件中通过 `navigator.sendBeacon('/api/exit')` 主动通知后端立即退出。
- **界面显式退出按钮**：控制台顶部右上角新增「退出程序」按钮，点击确认后调用 `/api/exit` 优雅退出服务并关闭浏览器窗口。
- **默认无参全自动**：单文件便携版双击启动，以及安装版快捷方式均默认启用 `--auto-exit`，使用完毕随手关掉窗口即可彻底释放文件占用，不再出现文件无法删除/移动的问题。

#### 2. 🏷️ Windows PE 元数据规范化补齐
- **修正文件说明**：单文件 EXE 编译参数中追加 `--windows-description=agent-purge`。
- **告别 Bun 提示**：彻底消除 Windows 系统占用提示框中将程序描述识别为第三方底层运行时的混淆现象，确保进程说明与数字签名均清晰显示为 `agent-purge`。

### 📦 安装与升级 (Installation & Upgrade)

#### npm 全局安装 / 升级：
```bash
npm install -g agent-purge@latest
agent-purge web
```

#### 便携版 EXE / 安装器：
可在本 Release 附件中下载最新发布的 `agent-purge.exe`（单文件独立版）或 `agent-purge-0.2.15-setup.exe`。
