# agent-purge v0.2.34

### 🪟 控制台有了自己的窗口（WebView2）

- 瘦包与安装器新增 `agent-purge-window.exe`：窗口属于 agent-purge 自己——没有地址栏、没有标签页、没有浏览器账号，任务栏图标就是本应用。
- 不再借 Chrome / Edge 的 `--app` 模式，因此也不会再出现「一个本地工具在要 Microsoft 账号授权」：Edge 的首启一定会把系统里已登录的 Microsoft 账号关联进新 profile（`--disable-sync`、`--disable-features=ImplicitSignIn` 实测都拦不住），这条路直接绕开。
- 关窗确认改由窗口宿主弹原生对话框，仍按「设置」页的「关闭窗口前先确认 / 关闭窗口时」执行，未保存草稿也会先问一句；窗口位置与大小会被记住。
- 没有 WebView2 Runtime、用 npm 安装、或用免安装单文件 `agent-purge.exe` 时，自动退回 Chrome 的 `--app`（没有 Chrome 才用 Edge），再不行交给系统默认浏览器。
- 构建期用到 WebView2 SDK（版本与 sha256 钉死、头文件与手写 IID 对账），`WebView2Loader.dll` 随包分发；宿主缺失或不健康时不阻塞打包。

### 🌙 深色模式（#19，感谢 @hzluoty）

- 顶栏右侧日 / 月按钮一键在浅色与深色之间切换，立即生效并保存。
- 「设置」页新增「外观主题」三态：自动（跟随系统）/ 浅色 / 深色。
- 首屏由服务端按已保存的主题注入 `data-theme`，深色下不会先闪一下白底；深色配色经过 WCAG 2.1 AA 对比度校验，浏览器端到端用例覆盖五个页面。
