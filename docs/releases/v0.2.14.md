# agent-purge v0.2.14

### 🌟 核心更新亮点 (Highlights)

#### 1. 🤝 WorkBuddy 双通道深度接管与 100% 无残留还原
- **根因突破**：彻底解决 WorkBuddy 仅修改 `settings.json` 的 `customPrompt` 时，提问身份仍被底层 `~/.workbuddy/user-*/IDENTITY.md`（Name）与 `SOUL.md`（灵魂人设）压制的问题。
- **双通道协同**：自动扫描并接管所有 `user-*` 目录，同步更新 `IDENTITY.md`（AI 名字）、`SOUL.md`（人设正文）、`USER.md`（用户称呼）以及 `settings.json`（customPrompt）。
- **原字节备份退避**：在 `stash/workbuddy-users/` 建立原始字节备份，点击关闭（disarm）时 100% 原样还原，不修改云端 private-configs，无任何数据残留。

#### 2. ⚡ 新增 Kilo Code 全模式真实二进制抓包支持
- **原生适配**：支持 `@kilocode/cli`（7.8.18），覆盖 code agent prompt（replace / strict）与 `AGENTS.md` 托管块（append）。
- **全模式抓包验证**：通过真实隔离 loopback provider 完成 off / strict / replace / append 四模式全量请求抓包，确认测试人设标记 100% 稳定落入 `system` 角色层。

#### 3. 🛡️ DeepSeek Harness (DSH) 全形态抓包与状态同步修复
- **三形态全覆盖**：完成 DSH 的 Headless、Web 以及基于 Electron CDP 的 Desktop 桌面版真实请求抓包，请求角色与 sections 剥离效果经受实测检验。
- **抽屉状态修复**：重构 `persist.probe`，使用 `hasPluginAny` 消除多 profile（desktop/web/headless）未对齐导致的状态显示撕裂。

#### 4. 🚀 控制台双模一键自动更新 (npm / EXE)
- **双源毫秒级探测**：进入控制台或点击版本标签时，并发查询 npmjs 官方/国内镜像与 GitHub Releases，精准呈现最新版本号与发布日志。
- **现代化更新弹窗**：支持版本对比、变更日志直接预览以及终端安装命令一键复制。
- **双模自动升级**：
  - **npm 全局安装**：支持在 Web 界面点击「一键执行 npm 升级」，后台全自动完成安装并提示刷新。
  - **便携版 EXE**：支持「一键就地升级」，利用 Windows 文件原子重命名技术安全热替换当前正在运行的可执行文件。

#### 5. 🎨 Web 控制台下拉菜单全量重构与美化
- **告别原生控件**：全面消除 Windows 原生 `<select>` 的粗糙直角弹出框，换用全新现代化自定义浮层组件（Custom Select）。
- **细腻交互质感**：圆角卡片、柔和阴影、SVG 旋转箭头、选项悬浮浅蓝过渡、选中项对勾标记，并支持视口边界自适应翻转。

#### 6. 🌐 国际化支持：中 / 英 / 日 三语 README
- 新增 `README.en.md`（英文）与 `README.ja.md`（日文），并在主 README 头部提供清晰的语言切换导航。

### 📦 安装与升级 (Installation & Upgrade)

#### npm 全局安装 / 升级：
```bash
npm install -g agent-purge@latest
agent-purge web
```

#### 便携版 EXE / 安装器：
可在本 Release 附件中下载最新发布的 `agent-purge.exe`（单文件独立版）或 `agent-purge-0.2.14-setup.exe`。
