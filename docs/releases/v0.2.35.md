# agent-purge v0.2.35

## Windows 桌面修复（#20）

- 窗口宿主与薄启动器静态链接 MinGW 运行库，不再依赖安装包外的
  `libgcc_s_seh-1.dll`、`libstdc++-6.dll`、`libwinpthread-1.dll`。
  构建时校验导入表，发现动态依赖或无法校验时拒绝发布。
- 原生窗口启动即失败时落诊断日志并回退浏览器；单例登记使用实际回退窗口 PID。
- 修复受限 PATH 下聚焦失败导致重复开窗；固定使用系统 PowerShell 路径。
- 正在运行的启动器和原生窗口会阻止安装器替换或删除程序文件，避免卸载残留。

## 卸载与预览安全

- 卸载在用户确认后才撤销接管，取消确认不会改配置。
- 无法撤销的旧文件/自定义账本可跳过并留痕，恢复凭据原地保留；
  配置、账本读取、活跃通道、PATH 等严重错误仍阻止卸载。
- 修复损坏配置触发的二次异常，以及重复处理已还原文件的问题。
- `clean --dry-run` / `self-uninstall --dry-run` 不初始化或迁移用户数据、
  不回滚 journal、不写日志。
- 去掉“专属”徽标，各工具展示统一；独立人设选择与 DSH 形态设置仍保留。

## 验证与跨平台产物

- Windows 实际安装、重装、窗口、单例、关窗、冲突与卸载共 14 项验收通过，
  并核对测试未改变真实用户配置。
- 发布流程检查 Windows、Linux、macOS × Node 20/22/24。
- Linux x64 / ARM64 分别在原生架构 runner 执行单文件、便携包安装、
  Debian 包安装/运行/卸载及可选 AppImage 的验收，不仅交叉编译。
- Windows ZIP、setup、独立 EXE；Linux x64/ARM64 单文件、tar.gz、deb
  及可选 AppImage；macOS arm64/x64 DMG。校验值见 Release 的 `SHA256SUMS.txt`。
- macOS DMG 仍未签名/公证；首次运行需按系统安全提示手动允许。
