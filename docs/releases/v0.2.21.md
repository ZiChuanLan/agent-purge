# agent-purge v0.2.21

### 🔧 修复 (Fixes)

#### 1. 🧷 家目录含单引号时 dsh patch 变成非法 YAML
- **现象**：`~` 路径里带单引号（例如 `C:\Users\O'Brien`）时，`cordis.patch.yml` 里写的 `file:` URL 未转义，dsh 启动解析 patch 直接报 `Unexpected scalar at node end`。
- **修复**：写进 YAML 单引号标量前按规范把 `'` 双写成 `''`；空格与中文本来就由 URL 编码处理。已用真实 dsh 的 YAML 解析器与 `import()` 复验：带空格、中文、单引号的路径安装后 patch 可解析、插件可加载。

#### 2. 🧹 迁移旧布局后不再留空 `node_modules`
- 0.2.20 迁移旧插件目录后会在 profile 下留一个空 `node_modules`。现在只有在确实清掉自己的副本时才顺手收掉这个空目录；里面还有别的包就原样保留。

```bash
agent-purge install dsh
```
