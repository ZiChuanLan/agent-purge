# agent-purge v0.2.23

### 🔧 修复 (Fixes)

#### 1. 🐛 修复 DSH 激活会话热切插件报错 `ReferenceError: hostProfile is not defined`（Issue #12）
- **现象**：在 DSH 0.2.2（及 0.2.1）下启用热切插件 `agent-purge-slash` 启动时，抛出 `ReferenceError: hostProfile is not defined at Object.apply [as callback]`，导致插件激活失败。
- **根因**：v0.2.20 将插件包迁移至数据目录时，`apply(ctx)` 引入了从宿主 `profileContext` 读取 profile 名字的动态推导机制。但在 `slashSource` 插件模板中遗漏了 `hostProfile(ctx)` 函数定义，且模块内顶层变量写为 `const PROFILE`，导致即使补齐函数也会报 `TypeError: Assignment to constant variable`。
- **修复**：
  - 在 `slashSource` 中补齐 `hostProfile(ctx)` 并在顶层定义 `let PROFILE = PROFILE_FROM_PATH;`，与 `residentSource` 保持完全一致。
  - 增加单元测试，对生成的 `slashSource` 模块进行真实动态加载与 `apply(ctx)` 回调执行测试，覆盖 profile 动态提取与 `/purge on|mode|status|off` 命令注册与状态写入。
