# agent-purge v0.2.26

### ✨ 改进 (Improvements)

#### 1. 🎨 Antigravity 在 Web 控制台的图标与通道文案
- **图标**：Web 控制台里原先只有首字母占位头像。图标从本机 `resources/app.asar` 的 `icon.png` 提取（512×512，SHA256 `b27f0e4a…` 与 asar integrity 记录一致），落到 `web/assets/antigravity.png`。
- **抠白底 + 裁边**：官方图标自带白色圆角底板，彩色 `A` 只占画布 60%，直接缩到 24px 时视觉重量明显比 zcode / kilo / workbuddy 这类铺满格子的图标弱一档。现在按「白底转透明 → 裁到 `A` 的 ink 边界 → 留 14% 内边距」重新生成 128×128（11 KB），四角 alpha=0，24 / 28 / 34 三档在白底与深底上都与其它家对齐。
- **通道文案**：抽屉里按真实能力显示 —— 常驻配置（全局）可用、本项目规则可用；会话内热切与命令入口各自给出真实原因，不再出现「只有二进制补丁」的旧说明。
- **验证页**：`agy` 被识别为 `隔离 CLI` 执行器，`/api/verify` 走同一条 Gemini 原生协议抓包链路（`systemInstruction.parts`），返回 `captured / 15843 字 / system 层`。

已在本机 Web 控制台逐项核过：图标签名为 `antigravity`、`naturalWidth=128`；开关走 `/api/arm` 关→开两次，`~/.gemini/config/AGENTS.md` 随之删除与重建；`/api/verify` 返回 `injected.sys=true`、`chars=15843`。

#### 2. 🔌 magpie 网关插件：可视化生效范围（全部 / 仅勾选 / 排除）
- **新字段 `disabledAgents`**：插件 options 增加排除名单，优先级高于 `agents` 白名单；`hooks.js` 在 `agents` 判定之前先查它，命中即原样放行并 `report("skipped", 0)`。
- **插件管理页**：新增「范围」三选一（全部生效 / 仅勾选生效 / 排除勾选）与可勾选的 Agent 面板；预置 claude、codex、opencode、pi、dsh、antigravity、hermes、cursor、gemini，并支持输入自定义标识（`kilo`、`zcode` 之类）后加入列表，不必再手动改 JSON 选项。
- **状态行**：排除模式下显示「已排除 a / b」，与白名单模式的「只对 a / b 生效」对称。
- **人设列表兜底**：`gen-personas.mjs` 还没跑过时，页面回落到内置的「中性助手 / 极简」两项，不再是一片空白。
- **回归**：`test/magpie/hooks.test.mjs` 补 3 条（排除命中放行、排除未命中正常改写覆盖全部协议）；`test/magpie/page.test.mjs` 补 8 条（三种范围切换、勾选写入、状态行文案、自定义 agent、全部生效时清空并隐藏面板）。

> 插件不在 agent-purge 的 npm 包里，按 `magpie-plugin/README.md` 从 git 克隆后 `magpie plugin add` 安装；本节的改动随仓库分发。
