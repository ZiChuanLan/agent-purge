# agent-purge v0.2.20

### 🌟 核心更新亮点 (Highlights)

#### 1. 🧩 修复 dsh 0.2.2 下插件 `ERR_MODULE_NOT_FOUND`（issue #11）
- **现象**：升级到 `@deepseek-ai/dsh` 0.2.2-rc.1 后启动报
  `agent-purge (agent-purge): failed to import: Cannot find package 'agent-purge' imported from C:\Users\xxx\.dsh\profiles\web\`。
- **根因**：插件包原先手写进每个 profile 的 `node_modules`。dsh 0.2.2 起 profile 依赖由 pnpm 的运行时解析表统一管理，该目录一旦被清理/重建，patch 里剩下的裸包名就再也解析不到（已在本机用同样的栈帧复现）。
- **修复**：插件包改放到 agent-purge 数据目录 `~/.agent-purge/dsh/<插件名>/`，patch 里用绝对 `file:` URL 引用。profile 重装依赖、删 `node_modules`、换 dsh 版本都不再影响加载；旧布局的副本在下次 `install` 时自动迁移并清理。
- **顺带**：插件不再靠自身路径猜 profile，改为运行时读宿主 `profileContext`（旧路径推导保留为兜底），所以 `dshProfiles` 勾选与 `/purge` 的按 profile 状态在单一插件包下依然准确。
- **验证**：`0.2.1-rc.5`（桌面版 CLI）与 `0.2.2-rc.1` 各跑一次真实 `dsh web`：无 `did not activate` 警告，`dsh.log` 记录 `apply … profile=web`。

#### 2. 🪟 修复 Windows `--app` 窗口隐藏与白块残留（issue #9）
- **根因**：`lib/window.mjs` 使用 `windowsHide: true` 启动浏览器。Windows libuv 将其转换为 `SW_HIDE`；当 Edge 未在后台运行时，Chromium 主窗口以 `WS_VISIBLE = 0` 创建，出现无标题栏、点击穿透、任务栏无图标但桌面残留 DirectComposition 纯白合成矩形的现象。
- **修复**：浏览器为 GUI 应用程序，启动时指定 `windowsHide: false`，确保窗口正常可见可交互。

#### 3. 🔌 端口占用时二次启动自动依附并开窗
- **现象**：老实例正在运行（如双击第二次 `agent-purge.exe` 或老会话未完全退出），端口 7788 报 `EADDRINUSE`，静默退出无任何提示或窗口。
- **修复**：遇 `EADDRINUSE` 时主动探测 `http://127.0.0.1:7788/api/state`；确认已有 agent-purge 服务正常存活后，直接调用 `openAppWindow()` 把窗口开到已有服务上并正常退出，避免静默黑洞。

#### 4. 🛡️ 完善合规守则与免责声明
- 在 README 与 `docs/LEGAL.md` 明确强调：本项目仅为本地多宿主配置管理工具，严禁用于对抗或未授权访问，不分发违规/越狱载荷。

#### 5. 🔄 修复 Web 控制台页面刷新导致本地服务误退出（PR #10）
- **根因**：页面卸载（F5/Ctrl+R 刷新）触发 `pagehide` 事件并直发 `/api/exit`，服务端误当作关机而立即退出进程。
- **修复**：将页面卸载与服务关停解耦，改为上报世代代号 `/api/leave?gen=N`。服务端引入 1500ms 退出宽限期，页面刷新时由新请求立即撤销倒计时，同时忽略旧页面迟到的 beacon。源码态永不因页面离开退出。

### ⬆️ 从 0.2.18 升级

- 0.2.19 未单独发布，本版本包含 0.2.19 与 0.2.20 的全部修复。
- dsh 用户升级后执行一次 `agent-purge install dsh`，把旧布局（写进 profile `node_modules`）迁到数据目录；之后无需再因 dsh 升级或依赖重装而重装插件。

### 📦 安装与升级 (Installation & Upgrade)

```bash
npm install -g agent-purge@latest
agent-purge web
```

便携版与安装器见本 Release 附件（`agent-purge.exe` / `agent-purge-0.2.20-setup.exe`）。
